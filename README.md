# [Flutter 과제] 백하윤

## 실행 방법

- **Flutter 버전**: Flutter 3.24.5
- **실행 명령**: `flutter run -d chrome --web-browser-flag "--disable-web-security"`
  _(모바일 에뮬레이터 구동 시 노트북 성능 저하 문제로 웹 환경에서 CORS 제한을 우회하여 사용했습니다.)_
- **확인한 플랫폼 및 기기**: Chrome 웹 브라우저 (Figma 기준 모바일 뷰포트)
- **폰트 처리 방식**: 시스템 기본 폰트를 사용하며, 제공된 디자인 토큰의 타이포그래피/간격 규격을 준수

## 구현 범위 (Scope)

- **01 · 관심 화면**: 완료

  - 상승/하락/보합 3가지 등락 색상 적용
  - 상단 새로고침 버튼 및 하단 탭 바 연동
  - 시세 미수신 종목 스켈레톤 상태 처리
  - 관심종목이 없을 때의 빈 상태 및 정렬 바텀시트 구현
- **02 · 검색 화면**: 완료
  - 검색 입력창 및 지우기 버튼 구현
  - 검색어 실시간 텍스트 하이라이트 처리
  - 별 아이콘을 통한 관심 등록/해제 및 하단 토스트 팝업 피드백 연동
  - 종목 상세 화면 라우팅 구조 마련
  - 검색 전 초기 상태 및 결과 없음 상태 구현
- **03 · 종목상세 화면**: 완료
  - 네이버 금융 실시간 시세 및 일별 시세 API 연동
  - 기간별 탭 전환 및 메모리 캐싱 적용
  - CustomPainter로 실제 증권 앱 스타일의 캔들 차트 구현
  - 시가, 고가, 저가, 거래량, 시가총액 정보 카드 동적 배치
- **상태 동기화**: 관심 상태 변경 시 화면 간 실시간 연동 구조 적용

### 선택 항목 추가 구현

## 기술 선택과 이유

- **상태 관리 및 아키텍처**: 직관적이고 가벼운 StatefulWidget 및 레포지토리 패턴으로 데이터 파싱과 UI 상태를 제어했습니다.
- **네트워크 및 데이터 처리**:
  - 관심종목 리스트를 심볼 기준으로 일괄 조회하여 API 호출을 최적화했습니다.
  - EUC-KR 인코딩 대응 및 메모리 캐싱 기법으로 탭 이동시 네트워크 낭비를 방지했습니다.
- **디자인 토큰**: 제공된 AppColors, AppDimens 시맨틱 토큰 구조를 반영하여 다크 테마를 구현했습니다.
- **목업 데이터 연동**: API 및 에셋 가이드에 따라 assets/mock/stocks.json을 구성하고 모델 직렬화 구조를 적용했습니다.

## 직접 판단한 부분과 이유

- **토스트 노출 시간 및 방식**: 사용자 경험을 해치지 않도록 일정 시간(1.8초) 노출 후 자연스럽게 페이드아웃 되도록 구현했습니다.
- **긴 종목명 오버플로 처리**: 화면 레이아웃이 깨지지 않도록 TextOverflow.ellipsis를 적용했습니다.
- **시세를 못 받은 행의 정렬 처리**: 현재가순 및 등락률순 정렬 시 가격 데이터가 없는(null) 스켈레톤 항목은 목록 최하단으로 배치하여 사용자가 실거래 종목을 우선 인지할 수 있도록 예외 처리했습니다.
- **캔들 차트 시각화 방식**: 외부 라이브러리 대신 Flutter 기본 CustomPainter를 활용하여 증권 앱 특유의 가변 꼬리 길이, 상승/하락 컬러, 박스 이탈 방지 로직을 가볍게 구현했습니다.

## 막혔던 지점과 어떻게 접근했는지

- **에셋 404 에러 및 경로 문제**: Flutter Web 빌드 과정에서 pubspec.yaml의 assets/mock/ 경로 누락과 파일을 만들지 않아 404 에러가 떴습니다. pubspec.yaml에 들여쓰기를 확인하여 에셋 경로를 등록하고, mock 폴더 내에 stocks.json 파일을 생성하여 해결했습니다.
- **네이버 일별 시세 HTML 파싱 및 부호 누락 문제**:
  - 네이버 웹 페이지 EUC-KR 인코딩 한글 깨짐 방지를 위해 바이트 단위 디코딩을 적용했습니다.
  - HTML 태그 내부의 등락 표시 구조상 텍스트 부호가 누락되어 모든 값이 양수로 인식되는 문제가 생겼습니다. 이를 해결하기 위해 당일 종가와 전일 종가의 차이를 비교하는 로직을 추가하여 등락액 계산과 하락시 파란색 색상 분기를 구현했습니다.
- **캔들 차트 꼬리 표현**: 처음에 고가/저가 데이터를 파싱하지 않아 꼬리 길이가 제대로 표현되지 않는 문제가 있었습니다. 그래서 HTML 파싱 단계에서 네이버 표의 고가, 저가 데이터를 추가 수집하여 실제 주식 차트처럼 매일 다른 꼬리 길이를 회색으로 표현했습니다.
